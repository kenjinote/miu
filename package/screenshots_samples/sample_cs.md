# miu - Ultralehký textový editor pro Windows

Vítejte v **miu**, moderním, bleskově rychlém a úsporném textovém editoru pro každý den.

## Hlavní funkce
- **Okamžité spuštění**: Připraven k práci během milisekund s minimální spotřebou paměti RAM.
- **Architektura Piece Table**: Plynulé otevírání a úpravy obřích logovacích souborů o velikosti gigabajtů.
- **Ukládání s oprávněním správce (UAC)**: Bezpečné ukládání chráněných systémových souborů.
- **Světlý a tmavý režim**: Dokonalé vizuální sladění s designem systému Windows 11.
- **Automatická detekce kódování**: Plná podpora UTF-8, UTF-16 a středoevropských znakových sad.
