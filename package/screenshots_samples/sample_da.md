# miu - Ultralet tekstredigeringsprogram til Windows

Velkommen til **miu**, en moderne, lynhurtig og ressourcebesparende teksteditor til Windows.

## Nøglefunktioner
- **Øjeblikkelig opstart**: Klar til brug på få millisekunder med minimalt RAM-forbrug.
- **Piece Table-arkitektur**: Åbn og rediger enorme logfiler på flere gigabyte helt uden forsinkelse.
- **Gem som administrator (UAC)**: Gem beskyttede systemfiler sikkert og nemt.
- **Lys og mørk tilstand**: Tilpasser sig automatisk til dit Windows 11-tema.
- **Automatisk registrering af tegnsæt**: Fuld understøttelse af UTF-8, UTF-16 og nordiske tegn.

// Eksempel: Hurtig initialisering i C
