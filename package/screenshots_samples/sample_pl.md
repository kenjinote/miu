# miu - Ultralekki edytor tekstu dla systemu Windows

Witamy w **miu** — niesamowicie szybkim i minimalistycznym edytorze tekstu.

## Główne zalety
- **Błyskawiczny start**: Otwiera się w ułamku sekundy przy minimalnym zużyciu pamięci RAM.
- **Architektura Piece Table**: Płynne otwieranie i edycja plików o wielkości wielu gigabajtów.
- **Zapis z uprawnieniami UAC**: Bezpieczne nadpisywanie plików chronionych w katalogu C:\.
- **Automatyczne kodowanie**: Pełne wsparcie dla UTF-8, ANSI oraz starszych stron kodowych.
- **Motyw jasny i ciemny**: Naturalne dopasowanie do stylu wizualnego Windows 11.

```c
// Przykład: Szybka inicjalizacja w C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Pozdrowienia z miu v1.0.29!
");
    return 0;
}
```
