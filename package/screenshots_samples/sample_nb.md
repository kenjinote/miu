# miu - Ultralett tekstredigeringsprogram for Windows

Velkommen til **miu**, en moderne, lynrask og ressursvennlig teksteditor for Windows.

## Viktige funksjoner
- **Øyeblikkelig oppstart**: Klar til bruk på millisekunder med minimalt minnebruk (RAM).
- **Piece Table-arkitektur**: Åpne og rediger enorme loggfiler på flere gigabyte uten forsinkelse.
- **Lagre som administrator (UAC)**: Lagre beskyttede systemfiler trygt og enkelt.
- **Lys og mørk modus**: Tilpasser seg automatisk til ditt Windows 11-tema.
- **Automatisk tegnsettgjenkjenning**: Full støtte for UTF-8, UTF-16 og norske tegn.

```c
// Eksempel: Rask initialisering i C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Hei fra miu v1.0.31!\n");
    return 0;
}
```
