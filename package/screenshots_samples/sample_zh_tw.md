# miu - 極速輕量 Windows 純文字編輯器

歡迎使用 **miu**，專為追求極致效能與簡潔優雅而打造的高效文字編輯器。

## 核心特色
- **瞬間啟動**：毫秒級極速冷啟動，不佔用多餘系統資源。
- **Piece Table 架構**：流暢開啟並編輯數 GB 等級超大檔案，毫無卡頓。
- **UAC 提權保存**：遇到 C 槽根目錄或受保護系統檔案時，可透過管理員權限安全儲存。
- **深色與淺色模式**：完美支援 Windows 11 系統色彩與精美介面。
- **多編碼自動辨識**：完整支援 UTF-8、Big5、ANSI 及各國編碼。

```c
// 範例：輕量化高效處理邏輯
#include <windows.h>
#include <stdio.h>

int main() {
    printf("你好！歡迎使用 miu v1.0.29
");
    return 0;
}
```
