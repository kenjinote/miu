# miu - Сверхлегкий текстовый редактор для Windows

Добро пожаловать в **miu** — быстрый, компактный и эффективный редактор текста.

## Ключевые возможности
- **Мгновенный запуск**: Запуск за миллисекунды без лишних фоновых процессов.
- **Архитектура Piece Table**: Плавная работа с файлами размером в несколько гигабайт.
- **Сохранение с UAC**: Надежное сохранение защищенных файлов с правами администратора.
- **Поддержка кодировок**: Автоматическое определение UTF-8, ANSI, CP1251 и других кодировок.
- **Светлая и темная темы**: Идеальная интеграция с системным интерфейсом Windows 11.

// Пример: Быстрая инициализация на C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Привет из miu v1.0.29!
");
    return 0;
}
