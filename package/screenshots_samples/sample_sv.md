# miu - Ultralätt textredigerare för Windows

Välkommen till **miu**, en modern, blixtsnabb och resurssnål textredigerare för Windows.

## Viktiga funktioner
- **Omedelbar start**: Redo att användas på några millisekunder med minimal RAM-förbrukning.
- **Piece Table-arkitektur**: Öppna och redigera enorma loggfiler på flera gigabyte helt utan fördröjning.
- **Spara som administratör (UAC)**: Spara skyddade systemfiler säkert och smidigt.
- **Ljust och mörkt läge**: Anpassar sig automatiskt efter ditt Windows 11-tema.
- **Automatisk kodningsdetektering**: Fullt stöd för UTF-8, UTF-16 och internationella teckentabeller.

```c
// Exempel: Snabb initiering i C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Hej från miu v1.0.31!\n");
    return 0;
}
```
