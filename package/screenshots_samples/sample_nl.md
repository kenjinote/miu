# miu - De ultralichte teksteditor voor Windows

Welkom bij **miu**, een uiterst snelle en efficiënte teksteditor voor Windows.

## Belangrijkste kenmerken
- **Bliksemsnelle start**: Onmiddellijk gebruiksklaar met minimaal geheugengebruik.
- **Piece Table-architectuur**: Bewerk moeiteloos gigantische bestanden van meerdere gigabytes.
- **UAC-beheerdersopslag**: Sla beveiligde systeembestanden veilig op met beheerdersrechten.
- **Universele codering**: Automatische detectie van UTF-8, ANSI en traditionele tekensets.
- **Lichte en donkere modus**: Sluit naadloos aan bij het thema van Windows 11.

```c
// Voorbeeld: Snelle start in C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Hallo vanuit miu v1.0.29!
");
    return 0;
}
```
