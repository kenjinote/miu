# miu - Εξαιρετικά ελαφρύς επεξεργαστής κειμένου για Windows

Καλώς ήρθατε στο **miu**, έναν σύγχρονο, ταχύτατο και αποδοτικό επεξεργαστή κειμένου.

## Κύρια χαρακτηριστικά
- **Άμεση εκκίνηση**: Έτοιμο για εργασία σε κλάσματα δευτερολέπτου με ελάχιστη χρήση μνήμης RAM.
- **Αρχιτεκτονική Piece Table**: Ανοίξτε και επεξεργαστείτε άνετα τεράστια αρχεία καταγραφής (logs) πολλών gigabyte.
- **Αποθήκευση με δικαιώματα διαχειριστή (UAC)**: Αποθηκεύστε με ασφάλεια προστατευμένα αρχεία συστήματος.
- **Φωτεινή και Σκοτεινή λειτουργία**: Αυτόματος συγχρονισμός εμφάνισης με το θέμα των Windows 11.
- **Αυτόματη αναγνώριση κωδικοποίησης**: Πλήρης υποστήριξη UTF-8, UTF-16 και ελληνικών γραμματοσειρών.

```c
// Παράδειγμα: Γρήγορη αρχικοποίηση σε C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Γεια σας από το miu v1.0.31!\n");
    return 0;
}
```
