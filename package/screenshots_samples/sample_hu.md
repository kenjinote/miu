# miu - Ultrakönnyű szövegszerkesztő Windowshoz

Üdvözli a **miu**, a modern, villámgyors és erőforrás-takarékos szövegszerkesztő.

## Főbb jellemzők
- **Azonnali indítás**: Ezredmásodpercek alatt munkára kész, minimális memóriahasználat mellett.
- **Piece Table architektúra**: Gigabájtos naplófájlok (logok) zökkenőmentes megnyitása és szerkesztése.
- **Mentés rendszergazdaként (UAC)**: Védett rendszerfájlok biztonságos mentése közvetlenül a szerkesztőből.
- **Világos és sötét mód**: Automatikusan illeszkedik a Windows 11 megjelenéséhez.
- **Automatikus karakterkódolás-felismerés**: Teljes körű UTF-8, UTF-16 és közép-európai támogatás.

```c
// Példa: Gyors inicializálás C nyelven
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Üdvözöl a miu v1.0.31!\n");
    return 0;
}
```
