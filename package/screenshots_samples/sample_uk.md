# miu - Надлегкий текстовий редактор для Windows

Ласкаво просимо до **miu** — надзвичайно швидкого, компактного та ефективного редактора тексту.

## Ключові переваги
- **Миттєвий запуск**: Готовий до роботи за частку секунди без фонового навантаження.
- **Архітектура Piece Table**: Плавна робота та редагування велетенських файлів у кілька гігабайтів.
- **Збереження з правами UAC**: Надійне збереження файлів у захищених системних каталогах (C:\).
- **Світла та темна теми**: Бездоганна інтеграція з сучасним дизайном Windows 11.
- **Автоматичне розпізнавання кодувань**: Точне визначення UTF-8, ANSI, CP1251 та інших кодувань.

```c
// Приклад: Швидка ініціалізація на C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Вітання з miu v1.0.30!\n");
    return 0;
}
```
