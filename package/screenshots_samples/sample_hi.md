# miu - Windows के लिए अल्ट्रा-लाइटवेट टेक्स्ट एडिटर

**miu** में आपका स्वागत है — एक आधुनिक, तेज़ और कम संसाधन लेने वाला टेक्स्ट एडिटर।

## मुख्य विशेषताएँ
- **तुरंत स्टार्टअप**: न्यूनतम RAM उपयोग के साथ पलक झपकते ही काम के लिए तैयार।
- **Piece Table आर्किटेक्चर**: गीगाबाइट आकार की बड़ी लॉग फ़ाइलों को बिना किसी रुकावट के खोलें और संपादित करें।
- **व्यवस्थापक अधिकार (UAC) सहेजें**: सिस्टम फ़ोल्डरों में सुरक्षित फ़ाइलों को आसानी से सहेजें।
- **लाइट और डार्क मोड**: Windows 11 थीम के साथ स्वचालित रूप से समन्वयित होने वाला सुंदर इंटरफ़ेस।
- **स्वचालित एन्कोडिंग पहचान**: UTF-8, UTF-16 और देवनागरी यूनिकोड का पूर्ण समर्थन।

```c
// उदाहरण: C भाषा में त्वरित आरंभिक कोड
#include <windows.h>
#include <stdio.h>

int main() {
    printf("miu v1.0.31 की ओर से नमस्ते!\n");
    return 0;
}
```
