# miu - โปรแกรมแก้ไขข้อความขนาดเบาพิเศษสำหรับ Windows

ยินดีต้อนรับสู่ **miu** โปรแกรมแก้ไขข้อความยุคใหม่ที่ทำงานรวดเร็วและประหยัดทรัพยากรเครื่องสูงสุด

## คุณสมบัติเด่น
- **เปิดใช้งานทันที**: พร้อมทำงานภายในเสี้ยววินาทีโดยใช้หน่วยความจำ (RAM) น้อยที่สุด
- **สถาปัตยกรรม Piece Table**: เปิดและแก้ไขไฟล์บันทึกข้อมูล (Log) ขนาดใหญ่ระดับกิกะไบต์ได้อย่างราบรื่น
- **บันทึกด้วยสิทธิ์ผู้ดูแลระบบ (UAC)**: บันทึกไฟล์ระบบที่ได้รับการป้องกันได้อย่างปลอดภัย
- **โหมดสว่างและโหมดมืด**: ปรับเปลี่ยนธีมสีให้เข้ากับระบบปฏิบัติการ Windows 11 โดยอัตโนมัติ
- **ตรวจสอบรหัสอักขระอัตโนมัติ**: รองรับ UTF-8, UTF-16 และภาษาไทยอย่างสมบูรณ์แบบ

```c
// ตัวอย่าง: โค้ดเริ่มต้นอย่างรวดเร็วในภาษา C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("สวัสดีจาก miu v1.0.31!\n");
    return 0;
}
```
