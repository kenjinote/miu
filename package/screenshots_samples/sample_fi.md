# miu - Erittäin kevyt tekstieditori Windowsille

Tervetuloa käyttämään **miu**-editoria — modernia, salamannopeaa ja kevyttä tekstieditoria.

## Tärkeimmät ominaisuudet
- **Välitön käynnistys**: Käyttövalmis millisekunneissa erittäin pienellä muistinkulutuksella.
- **Piece Table -arkkitehtuuri**: Avaa ja muokkaa sujuvasti jopa useiden gigatavujen kokoisia lokitiedostoja.
- **Tallennus järjestelmänvalvojana (UAC)**: Tallenna suojatut järjestelmätiedostot turvallisesti.
- **Vaalea ja tumma tila**: Mukautuu automaattisesti Windows 11 -käyttöjärjestelmän teemaan.
- **Automaattinen merkistöntunnistus**: Täysi tuki UTF-8-, UTF-16- ja pohjoismaisille merkistöille.

```c
// Esimerkki: Nopea alustus C-kielellä
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Tervehdys miu v1.0.31 -editorista!\n");
    return 0;
}
```
