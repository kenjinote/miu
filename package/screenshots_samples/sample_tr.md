# miu - Windows için Ultra Hafif Metin Düzenleyici

Hızlı, verimli ve modern bir metin düzenleyici olan **miu**'ya hoş geldiniz.

## Önemli Özellikler
- **Işık Hızında Başlangıç**: Sıfır gecikme ve minimum sistem kaynağı kullanımı ile anında hazır.
- **Piece Table Mimarisi**: Birkaç gigabaytlık devasa dosyaları donma olmadan akıcı şekilde düzenleyin.
- **UAC Yönetici İzniyle Kaydetme**: C:\ kök dizini gibi korumalı sistem dosyalarını güvenle kaydedin.
- **Geniş Kodlama Desteği**: UTF-8, ANSI ve yerel karakter kümelerini otomatik tanıma.
- **Koyu ve Açık Tema**: Windows 11 tasarım diliyle kusursuz görsel uyum.

```c
// Örnek: C ile Hızlı Başlangıç Kodu
#include <windows.h>
#include <stdio.h>

int main() {
    printf("miu v1.0.29'dan merhaba!
");
    return 0;
}
```
