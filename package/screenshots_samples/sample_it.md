# miu - Editor di testo ultraleggero per Windows

Benvenuto in **miu**, l'editor di testo progettato per offrire velocità istantanea ed eleganza.

## Caratteristiche principali
- **Avvio istantaneo**: Pronto all'uso in millisecondi con un consumo minimo di risorse.
- **Architettura Piece Table**: Modifica file enormi da svariati gigabyte senza rallentamenti.
- **Salvataggio con elevazione UAC**: Salva file protetti o di sistema con privilegi di amministratore.
- **Supporto codifiche universale**: Rilevamento automatico di UTF-8, ANSI e codifiche legacy.
- **Modalità Chiara e Scura**: Perfettamente armonizzato con l'interfaccia di Windows 11.
