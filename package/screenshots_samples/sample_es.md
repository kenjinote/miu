# miu - Editor de texto ultraligero para Windows

Bienvenido a **miu**, un editor de texto diseñado para ofrecer máxima velocidad y eficiencia.

## Características principales
- **Inicio ultrarrápido**: Apertura instantánea sin demoras ni consumo excesivo de memoria.
- **Arquitectura Piece Table**: Edite archivos gigantescos de varios gigabytes con fluidez total.
- **Guardado elevado UAC**: Guarde con permisos de administrador en carpetas protegidas como C:\.
- **Compatibilidad total**: Reconocimiento automático de UTF-8, ANSI y diversas codificaciones.
- **Modo Claro y Oscuro**: Se adapta a la perfección al tema de Windows 11.
