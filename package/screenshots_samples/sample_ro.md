# miu - Editor de text ultra-ușor pentru Windows

Bun venit în **miu**, un editor de text modern, extrem de rapid și eficient cu resursele sistemului.

## Caracteristici principale
- **Pornire instantanee**: Gata de lucru în câteva milisecunde, cu un consum minim de memorie RAM.
- **Arhitectură Piece Table**: Deschideți și editați fluent fișiere jurnal (log) de ordinul gigaocteților.
- **Salvare cu drepturi de administrator (UAC)**: Salvați în siguranță fișierele protejate ale sistemului.
- **Mod Luminos și Întunecat**: Integrare vizuală perfectă cu tema din Windows 11.
- **Detectare automată a codificării**: Suport complet pentru UTF-8, UTF-16 și diacritice românești.

```c
// Exemplu: Inițializare rapidă în limbajul C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Salutări de la miu v1.0.31!\n");
    return 0;
}
```
