# miu - Trình soạn thảo văn bản siêu nhẹ cho Windows

Chào mừng bạn đến với **miu**, trình soạn thảo văn bản hiện đại, tốc độ cao và tối ưu tài nguyên.

## Tính năng nổi bật
- **Khởi động tức thì**: Sẵn sàng làm việc trong chớp mắt mà không tốn dung lượng RAM.
- **Kiến trúc Piece Table**: Mở và chỉnh sửa mượt mà các tệp nhật ký (log) lớn hàng gigabyte.
- **Lưu với quyền quản trị (UAC)**: Lưu an toàn các tệp trong thư mục hệ thống như C:\.
- **Chế độ Sáng và Tối**: Tự động đồng bộ giao diện tuyệt đẹp với Windows 11.
- **Tự động nhận diện bảng mã**: Hỗ trợ toàn diện UTF-8, ANSI và các định dạng văn bản quốc tế.

```c
// Ví dụ: Mã khởi tạo nhanh bằng C
#include <windows.h>
#include <stdio.h>

int main() {
    printf("Xin chào từ miu v1.0.30!\n");
    return 0;
}
```
