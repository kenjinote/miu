# miu - Editor Teks Super Ringan untuk Windows

Selamat datang di **miu**, editor teks modern yang dirancang untuk kecepatan ekstrem dan efisiensi tinggi.

## Fitur Utama
- **Mulai Instan**: Terbuka dalam hitungan milidetik dengan penggunaan memori yang sangat hemat.
- **Arsitektur Piece Table**: Buka dan edit berkas raksasa berukuran gigabita tanpa hambatan.
- **Simpan dengan Izin UAC**: Simpan berkas sistem yang dilindungi (seperti root C:\) dengan aman.
- **Mode Terang dan Gelap**: Terintegrasi sempurna dengan tema visual Windows 11.
- **Deteksi Cerdas Enkod**: Mendukung penuh UTF-8, ANSI, dan berbagai halaman kode karakter.
